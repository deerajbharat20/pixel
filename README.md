# Wanderly — Travel Inspiration Website

A responsive travel-inspired landing page made with HTML, CSS and vanilla JavaScript.

## Project files
- `index.html` — page content and structure
- `style.css` — layout, colors, responsive styles
- `script.js` — mobile navigation, destination filters and demo newsletter form
- `favicon.svg` — browser tab icon

## Run
Open `index.html` in a browser. No build step is required.

The destination photographs and Google Fonts are loaded from external services, so an internet connection is needed for those assets.

## Publish on GitHub Pages
1. Create a GitHub repository.
2. Upload all files in this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.

## Note
The newsletter form is a front-end demo only. It displays a confirmation in the browser but does not store or send email addresses. Connect a backend or mailing-list service if you want real subscriptions.
